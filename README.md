# باناكس (Panax) — المرحلة الأولى

دليل بسيط لأطباء وأخصائيين في الرياض.

> **تنبيه:** الملفات المعلّمة «تجريبي» **وهمية** للعرض فقط، وتُحذف من لوحة الإدارة قبل الإطلاق.

## الصفحات

- **الرئيسية** `/` — تحية، بحث، التخصصات (جلدية، تجميل وليزر، عيون، أسنان، علاج طبيعي)، وبطاقات الأطباء.
- **صفحة الطبيب** `/doctors/[slug]` — الصورة (أو حرف الاسم إذا ما في صورة مسموح بها)، الاسم، المستشفى، التقييم من 5، نبذة، يعالج، معلومات، المصدر وتاريخ آخر تحقق، وزر واتساب.
- **المفضلة** `/favorites` — الأطباء المحفوظين (حاليًا على جهاز الزائر فقط).
- **الإعدادات** `/settings` — عن باناكس، الخصوصية، الشروط، طلب تصحيح/إزالة.

- **طلب تصحيح أو إزالة** `/corrections` — نحفظ فقط: الاسم، البريد، الصلة، الملف، الرسالة.
- **لوحة الإدارة** `/admin` — دخول برابط على البريد، عدة مشرفين (المالك أولهم):
  إضافة/تعديل/إخفاء الأطباء، رفع صورة بإذن الطبيب فقط، عدّاد ضغطات واتساب وهدف الـ90 يوم، وطلبات التصحيح.

شريط التنقل السفلي (الرئيسية · المفضلة · الإعدادات) عائم ومو ملاصق لأسفل الشاشة.

## التصميم (أسلوب Apple)

- خط الجهاز نفسه (SF Arabic على أجهزة Apple)، خلفية رمادية فاتحة ومجموعات بيضاء بزوايا دائرية.
- شريط علوي وسفلي شفافين (زجاجي) والمحتوى يمر تحتهم.
- استجابة فورية عند الضغط، وحركة نابضية (spring) بدون ارتداد إلا للقلب عند الحفظ.
- وضع ليلي تلقائي، ويحترم إعدادات تقليل الحركة والشفافية وزيادة التباين.

## مفتاح الإطلاق

- `SITE_LIVE=false` (الافتراضي): مخفي عن Google، شارة «تجريبي»، والملفات التجريبية ظاهرة.
- `SITE_LIVE=true`: يظهر في محركات البحث، بدون شارة، والملفات التجريبية مخفية.
- `NEXT_PUBLIC_SITE_URL`: عنوان الموقع (غيّره بعد شراء الدومين). بعد تغيير أي متغير: Redeploy في Vercel.

## قواعد مطبّقة

- الملف يظهر للزوار فقط إذا كان **منشور** وغير مخفي، ولازم يكون له **تاريخ موافقة** الطبيب (قاعدة البيانات تمنع غير كذا).
- لا تقييمات ولا نجوم في أي مكان عام (الأعمدة باقية في قاعدة البيانات بس ما تنعرض).
- الصورة ما تنرفع إلا بعد تأكيد «الطبيب وافق على الصورة».
- الترتيب أبجدي — لا يُباع.
- عدّاد واتساب يحفظ **العدد والتاريخ فقط** لكل ملف، مع حد للضغطات المتكررة.
- لوحة الإدارة: دخول برابط على البريد لقائمة إيميلات محددة فقط، والحماية على الخادم (proxy + فحص في كل صفحة + RLS).
- سجل تغييرات لكل تعديل. وجدول جاهز لميزة «استلام الطبيب لملفه» مستقبلًا (غير مفعّلة).

## صفحات محركات البحث

- `/riyadh/[تخصص]` صفحة لكل تخصص مع مقدمة و5 أسئلة شائعة.
- `sitemap.xml` و `robots.txt` (تسمح لمحركات البحث والمساعدات الذكية فقط بعد الإطلاق).
- بيانات منظمة JSON-LD: Organization، Physician، BreadcrumbList، FAQPage — بدون أي تقييم.

## التصميم (أسلوب Apple)

- خط الجهاز نفسه (SF Arabic على أجهزة Apple)، خلفية رمادية فاتحة ومجموعات بيضاء بزوايا دائرية.
- شريط علوي وسفلي شفافين (زجاجي) والمحتوى يمر تحتهم.
- استجابة فورية عند الضغط، وحركة نابضية (spring) بدون ارتداد إلا للقلب عند الحفظ.
- وضع ليلي تلقائي، ويحترم إعدادات تقليل الحركة والشفافية وزيادة التباين.

## قواعد مطبّقة في قاعدة البيانات

- الملف الجديد يبدأ **مخفي** لين يظهره مشرف.
- ما نحفظ أي بيانات عن الجنسية.
- أخصائي العلاج الطبيعي ما ينكتب «د.» إلا بملاحظة عن المستند اللي يثبته.
- **ما فيه إدخال تقييم من الإدارة** — الملف ما يقيّم نفسه. (التقييمات الظاهرة حاليًا في الملفات التجريبية فقط.)
- الصورة ما تنرفع بدون تأكيد **إذن الطبيب**.
- عدّاد واتساب يحفظ **العدد والتاريخ فقط** لكل ملف — ولا شيء عن الزائر.

## للمطوّرين

```bash
npm install
ADMIN_DEV_LOGIN=1 npm run dev   # http://localhost:3000 ؛ الإدارة على /admin (دخول محلي بدون كلمة مرور)
npm test
npm run typecheck
npm run build
```

- محليًا: قاعدة بيانات داخلية في `.data/` تُنشأ تلقائيًا مع الملفات التجريبية.
- الإطلاق: عبّي `DATABASE_URL` و `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` و `ADMIN_OWNER_EMAIL`
  (شوف `.env.example`). الجداول تُنشأ تلقائيًا أول مرة. الدخول المحلي يتعطل تلقائيًا إذا وُجد Supabase أو Vercel.
- معاينة على Vercel بدون Supabase: تشتغل مباشرة بقاعدة بيانات مؤقتة فيها الملفات التجريبية (لوحة الإدارة تبقى مقفلة).

- قاعدة البيانات والجداول: `src/lib/db/`
- القراءة للموقع: `src/lib/data/` ؛ الإدارة: `src/lib/admin/` و `src/app/admin/`
- الأنواع والبحث: `src/lib/doctors.ts`
- المفضلة: `src/lib/favorites.ts`
- الشعارات: `src/components/Logo.tsx` (والأيقونة `src/app/icon.svg`)
- التصميم: `src/app/globals.css`
